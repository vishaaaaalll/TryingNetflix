# TryingNetflix

A Netflix-style streaming demo site, built from scratch as a learning project.

## What it is

- A single-page static site: dark theme, top navigation, hero billboard,
  horizontally scrolling rows (Trending Now, Original Series, Films, Comedy,
  Documentaries), title detail modals, a working search filter, and a
  My List that persists in the browser's local storage.
- No build step, no backend, no third-party requests. Open `index.html`
  or serve the folder statically.
- The layout follows the public homepage pattern found during
  investigation: ranked trending row, benefits cards, FAQ accordion,
  email signup block, and a multi-column footer, plus a browse-style
  billboard and rows.

## What it is not

- It is **not** Netflix, and it is not affiliated with, endorsed by, or
  connected to Netflix, Inc.
- Every title, description and poster is invented for this demo. Posters
  are plain CSS gradients, not artwork. No Netflix code, images, videos,
  logos or copy were used. The layout follows only the general structure
  of a streaming homepage (navigation, hero, rows, footer), which is a
  common UI pattern.

## Run it

Serve this folder with any static server, or publish it with GitHub Pages
(Deploy from a branch, main branch, root folder).
